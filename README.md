# snipit.sh

Share code from VS Code via snipit.sh — no login, expire, burn-after-read.

Share the current file or selection as a snipit.sh link. AES-256 at rest. Optional password, expiry, and burn-after-read. No account.

CLI: `npm i -g snipit-sh`
Site: https://snipit.sh
Docs: https://snipit.sh/cli · https://snipit.sh/docs
Privacy: https://snipit.sh/privacy
